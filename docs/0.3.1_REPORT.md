# 0.3.1 rebuild and engine onboarding

Rebuild of version 3 on development/0.3.0. New version 0.3.1; main and the 0.2.0
branch remain untouched. No engines or neural networks are bundled.

The top-level A/B engine buttons now open a real file picker directly from every
workspace. Selected paths and names are prefilled. Executables do not start until
the user clicks Test engine. The dialog then explains Save engine. Optional engine
options and expert configuration are collapsed; default settings remain usable.
The first saved engine is selected for both sides for self-play. Subsequent loads
are assigned to the requested side. The last engine directory is remembered.

Unload buttons close paused idle engine processes and clear the selected side
without deleting saved profiles/history. Match start now rejects a missing side
rather than inadvertently selecting the last profile through index -1. Management
controls are grouped away from the basic setup. Welcome text appears above the
fields; opening books have an adjacent Browse action and pair count has help text.
The UI was rendered and inspected at 1280×800 before packaging.

Tests: 67 passed, 1 optional real-engine integration test skipped. Added behavior
checks for direct file-picker activation/cancel, prefilling without automatic
execution, intentional protocol test/save, assignment to A/B, unloading and
retaining saved profiles. Existing 0.3.0 regressions remain passing.

Windows packaging now supplies standard file/product version resources. This is
not Authenticode signing. No signing certificate or signing service is configured
in this build workflow, and a rebuilt unsigned executable can still be blocked
by Smart App Control/SmartScreen. Neither a version-resource change nor CI smoke
testing demonstrates reputation/trust approval on the user's Windows machine.
Do not claim that this rebuild fixes that security decision or advise disabling
Windows protection. The exact reported Windows message remains unconfirmed.

The Windows workflow tests, packages and runs an offscreen executable startup /
render smoke before uploading the new versioned artifact. Verified results and
its actual download URL are appended after the workflow completes.
