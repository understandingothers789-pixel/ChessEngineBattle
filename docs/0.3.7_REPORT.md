## Engine thinking

Starting/resuming opens Live Match on the right. New settings use playing MultiPV
3; existing saved counts are preserved. Each panel labels the engine, color,
originating ply, depth and nodes. The previous engine search remains visible while
the opponent thinks. Hover PV moves for a compact preview based on that search's
position; it does not alter the live board. New games clear previous-game lines.
The engines search alternate positions; these panels do not imply same-position
agreement. Clicking a played move opens the verified source search's final ranks
in comparison, including searches below the first checkpoint. Arrow navigation
continues to inspect positions normally.

## Adjudication

The top-bar dialog pauses the current game while a result is chosen. It restores
the previous running state on cancel or on completion. A running match proceeds
to its next scheduled game after adjudication; a paused match remains paused.
Draw, White wins and Black wins are explicit overrides. Evaluation agreement
uses the latest exact rank-1 cp score from each engine's last completed search,
requiring those searches to represent the last two consecutive plies. Scores
are normalized to White's perspective. Default manual thresholds are ±0.50 pawns
for a draw and at least 2.00 pawns for both engines favoring the same winner;
thresholds are editable. Missing, stale, bound, mate or disagreeing scores leave
the game unfinished.

Automatic draw by evaluation agreement defaults on for new matches and may be
disabled in Match Setup. After move 50, each completed ply checks that the latest
score from both engines is within ±0.20 pawns. Ten consecutive qualifying plies
end the game with the reason "Draw by evaluation agreement", including threshold,
ply count and move boundary. An out-of-range or missing exact score resets the
streak. Interrupted searches do not count. Natural game outcomes take precedence.
Scores, streaks, result, reason and source search IDs persist; PGN includes the
termination reason. Clocks and the current search stop on adjudication.

## Validation

Windows CI passed 104 tests, with one optional real-engine test skipped. Tests
include score perspective/bounds, stale and conflicting scores, threshold
boundaries, the move-50 exclusion and ten-ply rule, persisted manual outcomes,
freezing the adjudication dialog, missing agreement preserving play, low-budget
final MultiPV retention, automatic live selection and PV previews.

Windows PyInstaller packaging and packaged startup/render smoke passed. Linux
source startup and offscreen visual inspection also passed. Application package
metadata and PyInstaller exclude opening books. The independently uploaded book
artifact contains the three existing Stockfish-repository suites and their CC0
license/source notes. The original Nocturne project was not modified.

The executable remains unsigned. Interactive Windows desktop behavior and local
Smart App Control/SmartScreen acceptance were not verified. Real Stockfish search
behavior must be checked with the user's selected executable; the automated UCI
tests use a deterministic protocol fixture.
