# 0.3.4 combined build

Based on compatibility/0.3.1-rebuild, whose artifact the user confirmed runs on
their PC. Import the application modules, regression tests and benchmark script
from development/0.3.0, incorporating the 0.3.2 tooltip coverage and 0.3.3 speed
and correctness fixes. The 0.3.1 compatibility branch is preserved unchanged.

Included features: tooltips for standard controls and discovered engine options;
stat-keyed, bounded executable/network hash caching; streamed file hashing;
incremental viewer replay and dirty-row updates; statistics refresh only when
results change; corrected selected-game attribution, pin state, experiment
isolation, unsupported-MultiPV failure status and numeric help text.

Retain NocturneBattle.spec, dependency declarations and the compatibility build
workflow with signature/hash/dependency reporting. Use an honest new version
0.3.4 in package/window/resource metadata. No executable obfuscation, security
policy changes, signing changes or engine binaries are introduced.

The combined source changes the executable content. A successful 0.3.1 run does
not establish Smart App Control approval for a different unsigned executable.
CI can validate tests, packaging and startup/render, but acceptance on the user's
Windows machine requires testing the actual new download. Do not claim the
working baseline makes the new binary trusted or byte-identical.

Tests and verified Windows artifact details are recorded after the build.
